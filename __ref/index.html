PRODUCT CAPABILITIES

Engineered to be Unseen

Three core subsystems working in concert to deliver invisible intelligence.

Stealth Execution

Leverages the Windows Display Affinity API to make the overlay completely invisible to all screen-capture and screen-share pipelines ΓÇö OBS, Zoom, Teams, Discord.

Audio Loopback

Captures system audio through the Windows Audio Session API loopback device. Real-time transcription of meeting audio without any virtual cable hacks.

Vision Context

Selective region capture feeds visual context to the model ΓÇö code editors, terminal output, documentation ΓÇö without exposing your full desktop.

HOW IT WORKS
