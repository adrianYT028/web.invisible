Invisible AI marketing site with Supabase auth and an Express server for access control.

## Local Development

1) Install dependencies
```
npm install
```

2) Create .env
```
SUPABASE_JWT_SECRET=your-supabase-jwt-secret
PORT=3000
```

3) Start the server
```
npm start
```

Open http://localhost:3000

## Deploy (Render)

- Build command: npm install
- Start command: npm start
- Env var: SUPABASE_JWT_SECRET
